# Daily Digest

An edition-based news journal in Hebrew (RTL) and English (LTR). Static Astro pages, JSON content, Zod validation, no database or runtime backend.

## Run

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

Node.js 22 or later is required. Astro 7.4.11 replaces the originally proposed Astro 5 because the latter has known vulnerabilities. The static architecture and edition schema are unchanged.

## Publish an edition

1. Add `public/data/YYYY-MM-DD/HHMM-type.json`.
2. Use schema version `2.0`. Valid types: `morning`, `premarket`, `open`, `mid`, `close`, `breaking`.
3. Include both `he` and `en` for every editorial text. `publishedAt` includes its timezone offset. The filename's time matches it.
4. Add real source links. Market values must be verified; an empty `marketRibbon` displays an explicit unavailable-data message. Chart points must be real observations, never illustrative trends. Optional `asOf` and `sourceUrl` retain market provenance.
5. Save tweet images as local WebP files under `public/media/YYYY-MM-DD/<editionSlug>/`. Only publish material that can be shared publicly.
6. Run `npm test && npm run build`.
7. Commit the edition, then `git pull --rebase origin main` and `git push origin main`.

`public/data/index.json` is generated by prebuild and ignored by Git. The latest edition populates `/` and `/en/`; each day and each individual edition also has a permanent URL. The day timeline and archive derive entirely from the generated index.

Static translations of social posts are labeled as translations/summaries. No third-party X embed script, cookie banner, tracking or live market request is shipped to readers.

## Cloudflare Workers Static Assets

`wrangler.jsonc` points to `dist/`. For Workers Builds, connect this GitHub repository, choose `main`, set build command `npm run build`, deploy command `npx wrangler deploy`, and Node.js 22. Set build variable `SITE_URL` to the verified production URL before publishing, so canonical and hreflang URLs use the right host.

```sh
npm ci
SITE_URL=https://your-verified-production-host npm run build
npx wrangler deploy
```

No API tokens or Cloudflare credentials belong in GitHub source. A Cloudflare Git integration can deploy every push using its own connection; a separate GitHub Actions job validates, tests and builds.

## Routes and language

- `/`, `/en/`: latest edition.
- `/YYYY-MM-DD/`, `/en/YYYY-MM-DD/`: latest edition for a day.
- `/YYYY-MM-DD/HHMM-type/`, `/en/YYYY-MM-DD/HHMM-type/`: specific edition.

A first visit to a Hebrew URL uses browser language only when there is no explicit saved preference. The language switch preserves the current path and saves `digest_locale`. No auto-redirect ever runs on English pages. With JavaScript disabled, Hebrew remains the root default and both language links work.

## Accessibility and security

Semantic landmarks, skip link, focus indicators, reduced-motion support, local fonts, keyboard-operable archive, readable chart alternatives and pure SVG charts. News text is escaped by Astro; the schema restricts URLs to HTTPS or local paths. There is no raw user-authored HTML rendering. Security response headers are in `public/_headers`.
