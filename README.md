# Daily Digest

An edition-based news journal in Hebrew (RTL) and English (LTR). Static Astro pages, JSON content, Zod validation, no database or runtime backend. An official embedded market chart updates independently of the static edition.

## Run

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

Node.js 22 or later is required. Astro 7.4.11 replaces the originally proposed Astro 5 because the latter has known vulnerabilities. The static architecture and edition schema are unchanged.

## Publish an edition

1. Add `public/data/YYYY-MM-DD/HHMM-type.json`.
2. Use schema version `2.0`. Valid types: `morning`, `premarket`, `open`, `mid`, `close`, `breaking`.
3. Include both `he` and `en` for every editorial text. `publishedAt` includes its timezone offset. The filename's time matches it.
4. Add real source links. Market values must be verified; an empty `marketRibbon` displays an explicit unavailable-data message. Chart points must be real observations, never illustrative trends. Optional `asOf` and `sourceUrl` retain market provenance.
5. Do not publish copied social-post text, translations or downloaded images. Use independent news summaries and source links. Optional `socialPost` contains only the source post ID and URL. The prebuild rejects all copied `tweets` objects.
6. Run `npm test && npm run build`.
7. Commit the edition, then `git pull --rebase origin main` and `git push origin main`.

`public/data/index.json` is generated by prebuild and ignored by Git. The latest edition populates `/` and `/en/`; each day and each individual edition also has a permanent URL. The day timeline and archive derive entirely from the generated index.

Social-post copies, translated posts and archived images are not supported. Official X embeds are optional and click-to-load: no X network requests occur until the visitor agrees to connect. The official `https://platform.x.com/widgets.js` library renders posts with `dnt: true`; this does not mean no data is transmitted. The post is not translated. Missing, blocked or deleted posts show an unavailable state and a source link, not a local copy. Consent is saved for the browser session after the first explanation and confirmation. Each post still loads only on its own Show post click. Hiding removes its visible iframe, not the previous connection. The large market chart is native SVG, separate from static edition snapshots. No TradingView widget loads.

`wrangler.jsonc` points to `dist/`. For Workers Builds, connect this GitHub repository, choose `main`, set build command `npm run build`, deploy command `npx wrangler deploy`, and Node.js 22. Set build variable `SITE_URL` to the verified production URL before publishing, so canonical and hreflang URLs use the right host.

```sh
npm ci
SITE_URL=https://your-verified-production-host npm run build
npx wrangler deploy
```

No API tokens or Cloudflare credentials belong in GitHub source. A Cloudflare Git integration can deploy every push using its own connection; a separate GitHub Actions job validates, tests and builds.

## Routes and language

- `/`, `/en/`: latest edition.
- `/YYYY-MM-DD/`, `/en/YYYY-MM-DD/`: latest edition for a day.
- `/YYYY-MM-DD/HHMM-type/`, `/en/YYYY-MM-DD/HHMM-type/`: specific edition.

A first visit to a Hebrew URL uses browser language only when there is no explicit saved preference. The language switch preserves the current path and saves `digest_locale`. No auto-redirect ever runs on English pages. With JavaScript disabled, Hebrew remains the root default and both language links work.

## Accessibility and security

Semantic landmarks, skip link, focus indicators, reduced-motion support, local fonts, keyboard-operable archive, readable chart alternatives and pure SVG charts. News text is escaped by Astro; the schema restricts URLs to HTTPS or local paths. There is no raw user-authored HTML rendering. Security response headers are in `public/_headers`.

## Removing an X embed

On a deletion or takedown request, run `npm run remove-post -- POST_ID`, then test, build, commit and deploy the change. The command removes that reference from every edition and adds it to `public/data/removed-posts.json`. Prebuild prevents reintroducing it. Verify both language routes and the deployed `/data/` edition JSON no longer include the reference. A rebuild alone is not a takedown until the new assets are deployed. Source links and independent summaries are reviewed separately; this command only removes the embed.

There is no local cache of original X content. Each consent click asks the official widget for the post. X controls availability and may cache content on its own systems; publisher removal is provided by the command above, not a claim that the widget removes all copies instantly. The site does not poll X or resume scraping.

Official widget documentation:

## Native market quotes and themes

Relevant stories render native SVG sparkline strips and an optional native SVG main chart. Real source timestamps are displayed in the visitor's browser locale/timezone. Missing data is never replaced with an estimated price or invented series. A failed browser refresh retains that browser's last received quote with its original source time. Data older than 30 minutes receives a stale state. Historical edition prices and claims remain unchanged.

The accessible light-mode button follows the device preference until a choice is saved. Theme and language choices persist independently. Official X embeds require confirmation only before the first connection in that browser session, then a Show post click for each embed.

The old yfinance/market-data branch workflow is temporarily retained until the replacement has passed live CPU and source-connectivity checks. It is not used by the visitor-driven charts. Once verified, stop future scheduled collection and remove the unused current cache asset; preserve git history and the legacy branch unless separately approved.

### Visitor-driven charts

The native main chart and compact quote strips request `/api/market` from the existing Cloudflare Worker. `yahoo-finance2@4.0.6` runs server-side with `nodejs_compat`; browsers do not call Yahoo directly (its chart endpoints do not permit this site's origin through CORS). Only `/api/market` runs Worker code; all content and assets use static-first routing.

There is no database, KV, file or git write in this route. Requests in one page share fetched data. Worker requests use independent library instances; completed successful results may stay in a worker isolate's memory for 60 seconds. Memory may disappear at any time and is not shared worldwide. No visitor request means no data collection. The browser requests data at most every five minutes while visible and on range/asset selection. Quote and bar timestamps always come from Yahoo. Historical edition statements do not change with quotes.

Range labels describe actual returned bars. Charts are lines, not candlesticks. Intraday samples are five minutes apart; monthly/yearly samples are daily. "Up to 5 hours" does not fill missing hours before today's session begins. The large top price is the latest quote; chart-range change uses only the first and last returned bar. The axis endpoints show the actual bar dates/times in the visitor's browser locale/timezone.

#### Per-story chart selection

Prefer `marketCharts: [{"symbol":"MSFT","range":"1h"},{"symbol":"BTC-USD","range":"1mo"}]` on a story. Supported ranges are `1h`, `5h`, `1d`, `1mo`, `1y`. Each is required and drives both fetching and its visible label. `marketCharts` takes precedence over legacy `marketSymbols` (which means `1d`). New symbols use Yahoo's own symbol, for example `TSLA`, `BTC-USD` or `^GSPC`. Unknown symbols fail explicitly; never substitute a different asset. The old `BITSTAMP:BTCUSD` identifier is a compatibility alias for Yahoo `BTC-USD`, not a Bitstamp source. Source symbol is checked against the provider response.
