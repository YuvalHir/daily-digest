# Daily Digest

An edition-based news journal in Hebrew (RTL) and English (LTR). Static Astro pages, JSON content, Zod validation, no database or runtime backend. An official embedded market chart updates independently of the static edition.

## Run

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

Node.js 22 or later is required. Astro 7.4.11 replaces the originally proposed Astro 5 because the latter has known vulnerabilities. The static architecture and edition schema are unchanged.

## Publish an edition

1. Add `public/data/YYYY-MM-DD/HHMM-type.json`.
2. Use schema version `2.0`. Valid types: `morning`, `premarket`, `open`, `mid`, `close`, `breaking`.
3. Include both `he` and `en` for every editorial text. `publishedAt` includes its timezone offset. The filename's time matches it.
4. Add real source links. Market values must be verified; an empty `marketRibbon` displays an explicit unavailable-data message. Chart points must be real observations, never illustrative trends. Optional `asOf` and `sourceUrl` retain market provenance.
5. Do not publish copied social-post text, translations or downloaded images. Use independent news summaries and source links. Optional `socialPost` contains only the source post ID and URL. The prebuild rejects all copied `tweets` objects.
6. Run `npm test && npm run build`.
7. Commit the edition, then `git pull --rebase origin main` and `git push origin main`.

`public/data/index.json` is generated by prebuild and ignored by Git. The latest edition populates `/` and `/en/`; each day and each individual edition also has a permanent URL. The day timeline and archive derive entirely from the generated index.

Social-post copies, translated posts and archived images are not supported. Official X embeds are optional and click-to-load: no X network requests occur until the visitor agrees to connect. The official `https://platform.x.com/widgets.js` library renders posts with `dnt: true`; this does not mean no data is transmitted. The post is not translated. Missing, blocked or deleted posts show an unavailable state and a source link, not a local copy. Consent is per post per page visit. Hiding a post removes the visible iframe; it does not undo an earlier connection to X. The optional interactive market desk loads the official TradingView chart widget directly, retaining its branding and clearly distinguishing delayed equities from the provider's real-time crypto feed. It is separate from static edition snapshots. TradingView receives the embedding page URL, symbol and IP to deliver its widget; it states that widgets do not set cookies.

## Cloudflare Workers Static Assets

Production: https://daily-digest.hyuval1511.workers.dev

Initial deployment is live. Automatic Git-to-Cloudflare deployment is not connected yet; a Git push currently validates in GitHub Actions but still needs a manual Wrangler deployment. Do not assume a pushed edition is public until its live route and latest-edition links have been verified.

`wrangler.jsonc` points to `dist/`. For Workers Builds, connect this GitHub repository, choose `main`, set build command `npm run build`, deploy command `npx wrangler deploy`, and Node.js 22. Set build variable `SITE_URL` to the verified production URL before publishing, so canonical and hreflang URLs use the right host.

```sh
npm ci
SITE_URL=https://your-verified-production-host npm run build
npx wrangler deploy
```

No API tokens or Cloudflare credentials belong in GitHub source. A Cloudflare Git integration can deploy every push using its own connection; a separate GitHub Actions job validates, tests and builds.

## Routes and language

- `/`, `/en/`: latest edition.
- `/YYYY-MM-DD/`, `/en/YYYY-MM-DD/`: latest edition for a day.
- `/YYYY-MM-DD/HHMM-type/`, `/en/YYYY-MM-DD/HHMM-type/`: specific edition.

A first visit to a Hebrew URL uses browser language only when there is no explicit saved preference. The language switch preserves the current path and saves `digest_locale`. No auto-redirect ever runs on English pages. With JavaScript disabled, Hebrew remains the root default and both language links work.

## Accessibility and security

Semantic landmarks, skip link, focus indicators, reduced-motion support, local fonts, keyboard-operable archive, readable chart alternatives and pure SVG charts. News text is escaped by Astro; the schema restricts URLs to HTTPS or local paths. There is no raw user-authored HTML rendering. Security response headers are in `public/_headers`.

## Removing an X embed

On a deletion or takedown request, run `npm run remove-post -- POST_ID`, then test, build, commit and deploy the change. The command removes that reference from every edition and adds it to `public/data/removed-posts.json`. Prebuild prevents reintroducing it. Verify both language routes and the deployed `/data/` edition JSON no longer include the reference. A rebuild alone is not a takedown until the new assets are deployed. Source links and independent summaries are reviewed separately; this command only removes the embed.

There is no local cache of original X content. Each consent click asks the official widget for the post. X controls availability and may cache content on its own systems; publisher removal is provided by the command above, not a claim that the widget removes all copies instantly. The site does not poll X or resume scraping.
